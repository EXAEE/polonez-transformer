# Polonez Transformer

**Nowy elektryczny Polonez zaprojektowany od zera**  
z systemem Auto-Transform na dedykowanej platformie.

Open-source • Maintainability First • Circular DIY • Low-Cost

---

## Wizja

Nie konwersja istniejącego Poloneza.  
Całkowicie nowa konstrukcja, która:

- wizualnie i duchowo nawiązuje do Poloneza,
- jest od początku zaprojektowana pod transformację konfiguracji nadwozia,
- stoi na własnym, nowoczesnym, modularnym podwoziu (spaceframe / platforma),
- zachowuje zasady Maintainability First i Circular DIY.

Cel transformacji: jeden pojazd, który potrafi przyjmować kilka sensownych konfiguracji (hatchback / podwyższony użytkowy / otwarty truck / inne), zamiast budować osobne auta.

---

## Dlaczego nowa platforma od zera?

Próba pełnego Auto-Transform na oryginalnej karoserii Poloneza jest zbyt kompromisowa (sztywność, uszczelnienie, masa, bezpieczeństwo, homologacja).  
Dlatego **Polonez Transformer** zaczyna od czystej kartki:

- własne podwozie nośne,
- własne punkty mocowania segmentów nadwozia,
- własne systemy siłowników i blokad,
- własne rozłożenie baterii i napędu pod kątem zmiennej masy i środka ciężkości.

Oryginalny Polonez pozostaje inspiracją stylistyczną i kulturową, nie więzieniem technicznym.

## Główne założenia projektowe

### 1. Platforma (podwozie)
- Spaceframe lub hybrydowa rama rurowa + blachy
- Modularna – łatwa do wydłużenia / skrócenia
- Zaprojektowana pod różne konfiguracje nadwozia
- Wysoki priorytet serwisowalności i napraw w warunkach garażowych / polowych

### 2. Napęd
- W pełni elektryczny
- System kasetowy baterii (jak w linii Błyskawica)
- Power pack wymienny
- Możliwość RWD lub 4x4 w zależności od wariantu

### 3. System Auto-Transform
- Segmenty nadwozia (dach, boki, tył) zaprojektowane jako ruchome moduły
- Siłowniki elektryczne / hydrauliczne + mechaniczne blokady
- Sekwencyjne, bezpieczne przechodzenie między konfiguracjami
- Czujniki położenia + zakaz jazdy przy niezablokowanej pozycji

### 4. Konfiguracje docelowe (przykłady)
- **Hatch / Classic** – niska, codzienna sylwetka
- **Cargo / High** – podwyższony dach (użytkowy / karetka / kamper)
- **Truck / Open** – otwarta przestrzeń ładunkowa
- Ewentualnie inne motywy poprzez wymienne panele

### 5. Zasady nadrzędne
- Maintainability First
- Circular DIY + Low-Cost (druk 3D, spawanie, upcycling gdzie się da)
- Bezpieczeństwo strukturalne i HV nie podlega negocjacjom
- Pełna otwarta dokumentacja
